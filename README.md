# Paradox Chess Engine

Paradox is a UCI-compatible chess engine written in C++, its just a fun hobby that i like to work on.

## UCI Options

| Option | Description |
|---|---|
| **Hash** | Sets the transposition table size in MiB. A larger hash can store more previously searched positions. |
| **Threads** | Sets the number of CPU threads used for searching, currently a dummy placeholder. |
| **Clear Hash** | Clears the transposition table, removing previously stored search information. |
